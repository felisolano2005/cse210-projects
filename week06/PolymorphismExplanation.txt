Polymorphism is when we can use objects in the same way. We can treat them like they are the 
type but they can still do things differently. This is really helpful because it makes our code 
more flexible. It is easier to add things to our code without messing up what is already there.

One of the things about polymorphism is that we can add new types of things without 
changing the way our code already works. For example in my Eternal Quest program I have a 
list of goals.

I can use these goals in the way even though they are different types.

I can do something like this:

```

int earned = _goals[index].RecordEvent();

_score += earned;

```

Here _goals is a list of Goal. I have different types of goals like SimpleGoal, EternalGoal and 
ChecklistGoal. Each of these goals does the RecordEvent thing differently. This means I can use 
the line of code but it will do different things depending on what type of goal it is. This is 
polymorphism. It is really useful.
